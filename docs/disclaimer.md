# Disclaimer

## Independent Third-Party Project

**Shopee Historical Enrichment** is an independent third-party research and technical-learning project.

This project is **not affiliated with, endorsed by, sponsored by, or officially supported by Shopee**.

## Intended Use

This project is intended for:

- research and technical learning;
- personal data analysis;
- inspecting and enriching order-history data belonging to the user.

Use the project only with **your own Shopee account and your own data**.

## Security and Privacy

Never share or publish:

- passwords;
- cookies;
- session tokens;
- access tokens;
- personal addresses;
- phone numbers;
- tracking numbers;
- payment information;
- raw personal order-history datasets.

For screenshots, demonstrations, documentation, or public repositories, redact personal information before publishing.

## Scope and Limitations

This project is read-only in its intended use.

It does not claim to be an official Shopee API or a Shopee-approved integration.

The project depends on consumer web endpoints and browser-accessible data that may change without notice. Results may therefore vary between accounts and over time.

Historical enrichment does **not** automatically mean a complete historical archive. The project should not be interpreted as proof that every order ever created on an account has been recovered.

## Terms and Compliance

Users are responsible for using the project in accordance with applicable laws, platform terms, and account rules.

Do not use this project to access another person's account or data, bypass authentication or security controls, manipulate transactions, or obtain credentials, cookies, or session tokens.

## Project Status

This project is experimental and may change as research continues and as Shopee's consumer web interface and endpoints change.
