# Getting Started — Shopee Historical Enrichment

**Shopee Historical Enrichment v2.0**

A read-only browser-based research utility for inspecting and enriching a user's own Shopee order-history data.

> ⚠️ **Important:** This is an independent third-party project and is not affiliated with, endorsed by, or officially supported by Shopee.

---

## 1. About the Project

Shopee Historical Enrichment is a browser-based utility designed for:

- technical research;
- learning;
- historical data analysis;
- inspecting order data belonging to the user.

Main workflow:

```text
Shopee Order History
        ↓
Order ID Collection
        ↓
Individual Order Detail
        ↓
Processing Information
        ↓
TRUE Order Creation Timestamp
        ↓
Historical Enriched Dataset
        ↓
JSON + CSV
```

The utility is not intended to modify, submit, or manipulate user orders.

---

## 2. Who Is This Project For?

This project is suitable for users who want to:

- study their own Shopee purchase history;
- obtain more complete order dates;
- build a historical purchase dataset;
- analyze CSV/JSON data;
- perform JavaScript-based data experiments;
- understand how consumer-web order data is processed by the browser.

This project is **not** designed to:

- obtain data belonging to other users;
- access other people's accounts;
- bypass authentication;
- obtain passwords, cookies, or session tokens;
- modify orders;
- perform transactions automatically;
- interfere with Shopee systems.

---

## 3. Requirements

You need:

- your own Shopee account;
- a modern desktop browser;
- access to the Shopee Order History page;
- JavaScript enabled;
- sufficient space to store the generated JSON and CSV files.

Browsers such as Chrome, Edge, or modern Chromium-based browsers are generally suitable for this workflow.

---

## 4. Before You Start

Make sure you are using **your own Shopee account**.

Do not share or publish:

- passwords;
- cookies;
- session tokens;
- access tokens;
- payment-card information;
- full names;
- phone numbers;
- shipping addresses;
- tracking numbers;
- other personal information.

The dataset generated by this utility may contain personal information depending on the data available in the user's account.

**Do not upload your personal dataset to GitHub.**

## 7. Workflow Overview

In brief, v2.0 works as follows:

### Step 1 — Access Order History

The user opens their Shopee order history using their own account.

### Step 2 — Collect Order IDs

The utility collects order IDs available through the consumer-web order-history endpoint used by the browser.

### Step 3 — Request Order Details

Each order ID is processed to obtain its individual order details.

### Step 4 — Extract Processing Information

The utility reads information such as:

- order creation time;
- payment time;
- shipping time;
- completed time.

### Step 5 — Historical Enrichment

The order timestamp is used to enrich the historical dataset.

### Step 6 — Export

Data can be produced in:

```text
JSON
CSV
```
