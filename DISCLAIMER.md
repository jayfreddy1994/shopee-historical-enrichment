**Shopee Historical Enrichment** ialah projek pihak ketiga yang bebas dan tidak berafiliasi, disokong, ditaja atau disahkan secara rasmi oleh Shopee.

Projek ini disediakan untuk tujuan:

- dan analisis data order milik pengguna sendiri.

- atau melakukan aktiviti yang tidak dibenarkan oleh platform.

### Read-only

Projek ini direka sebagai penyelesaian **read-only** untuk mendapatkan dan menganalisis data yang tersedia kepada pengguna.

Ia bukan bertujuan untuk mengubah:

- order;
- pembayaran;
- alamat;
- akaun;
- atau data pengguna lain.

### Endpoint dan API

Projek ini tidak menggunakan atau mendakwa menggunakan **Shopee Public API rasmi**.

Ia menggunakan endpoint consumer web yang diperhatikan melalui browser sebagai sebahagian daripada penyelidikan teknikal.

Endpoint, parameter, response structure, field names, authentication mechanisms dan availability boleh berubah pada bila-bila masa.

Tiada jaminan diberikan bahawa source code akan terus berfungsi pada masa hadapan.

### Historical completeness

Penemuan order lama tidak semestinya membuktikan bahawa keseluruhan sejarah akaun telah berjaya diperoleh.

Sebagai contoh:

> **Oldest order found ≠ guaranteed oldest order ever**

Jumlah order yang diperoleh oleh sesuatu run juga tidak boleh dianggap sebagai jumlah mutlak lifetime order tanpa pengesahan tambahan.

### Endpoints and APIs

This project does not use or claim to use the **official Shopee Public API**.

### Historical completeness

Finding an older order does not necessarily prove that the complete account history has been retrieved.

For example:

> **Oldest order found ≠ guaranteed oldest order ever**

The number of orders returned by a particular run must not automatically be interpreted as the absolute lifetime order count without additional verification.
